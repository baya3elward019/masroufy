# مصروفي (Masrofy)

تطبيق ويب لإدارة المصروفات الشخصية — عربي، RTL بالكامل، بواجهة مستخدم عصرية بأسلوب تطبيقات الـ fintech.

## المميزات

- **لوحة تحكم** — ملخص يومي/أسبوعي/شهري، رسم بياني للإنفاق، توزيع حسب التصنيف، حالة الميزانية، آخر المصروفات.
- **إضافة/تعديل/حذف المصروفات** — نموذج سريع مع تصنيفات وطرق دفع بصرية، وتأكيد قبل الحذف.
- **صفحة المصروفات** — بحث، فلاتر (تصنيف / طريقة دفع / فترة زمنية / نطاق مبلغ)، جدول على الديسكتوب وكروت على الموبايل، تصدير CSV أو Excel.
- **التقارير** — نطاق تاريخ مخصص، إحصائيات تفصيلية (متوسط يومي، أعلى/أقل يوم، أعلى تصنيف...)، مقارنة بالفترة السابقة.
- **الميزانية** — ميزانية شهرية + ميزانيات لكل تصنيف مع تنبيهات عند 80% و100%.
- **التصنيفات** — إضافة / تعديل / حذف تصنيفات مخصصة (أيقونة ولون).
- **الإعدادات** — المظهر (فاتح / داكن / تلقائي)، تصدير البيانات CSV، إعادة تعيين.
- **حفظ محلي** — البيانات تُخزَّن في `localStorage` بالمتصفح، من غير أي سيرفر أو باك اند.

## التقنيات المستخدمة

React 18 + TypeScript + Vite + Tailwind CSS + Recharts + lucide-react.

## التشغيل محليًا

```bash
npm install
npm run dev
```

يفتح التطبيق تلقائيًا على `http://localhost:5173`.

## البناء للإنتاج

```bash
npm run build
npm run preview
```

الملفات الجاهزة للنشر هتلاقيها في مجلد `dist/`.

## ملاحظات

- البيانات المعروضة عند أول تشغيل هي بيانات تجريبية توضيحية (أغسطس ويوليو 2026) — بتتمسح تلقائيًا أول ما تضيف مصروف حقيقي وتُستبدل بالتخزين المحلي الفعلي.
- العملة الافتراضية جنيه مصري (EGP)، والبنية معمولة عشان تقدر تضيف عملات تانية بسهولة لاحقًا.
- التطبيق حاليًا بدون باك اند حقيقي؛ لو حبيت تضيف مزامنة سحابية أو حسابات مستخدمين لاحقًا، البنية (types.ts / storage.ts) مصممة عشان تستبدل طبقة التخزين بسهولة.
